# SimpleOS controls

The in-game overlay is intentionally simple: a few actions, no native DraStic menu.

## Home (DS-style)

| Action | Control |
| --- | --- |
| Move cursor | D-pad / analog stick / touch |
| Launch | **A** / tap |
| Archive | **X** |
| Options (Wi-Fi, power off, reboot) | **START** |
| Clock | **SELECT** |
|CPU&GPU governor| **Anbernic + RS** (up)|
| Volume | Volume **+** / **−** |
| Brightness (both screens) | Hold **Anbernic** + **L1** (down) / **R1** (up) |
| Sleep | Tap **POWER** / close the lid |
| Power off | Hold **POWER** |


## In-game overlay

Open and close with **Home/back**.\
To quickly switch between games use the Dpad left or right

Current game:

| Item | Meaning |
| --- | --- |
| RESUME | Close the overlay and continue |
| SAVE | Save state |
| LOAD | Load state |
|SLOT <>|Select current save state slot|
| ARCHIVE | Open the library menu |
|EMULATOR| Open emulator settings|
| RESET | Reset the emulator |


Confirm overlay actions with **A** or **START**.

## In-game shortcuts

| Action | Control |
| --- | --- |
| Fast-forward (toggle) | **Anbernic** + **SELECT** |
| Load state | **Anbernic** + **L2** |
| Save state | **Anbernic** + **R2** |
| Toggle FPS (off by default) | **Anbernic** + **X** |
| Microphone (drastic)| **R3**|
|CPU-GPU governor| **Anbernic + RS** (up)|
| Volume | Volume **+** / **−** |
| Brightness (both screens) | **Anbernic** + **L1** (down) / **MENU** + **R1** (up) |
| Sleep | Tap **POWER** / close the lid |
| Power off | Hold **POWER** |
