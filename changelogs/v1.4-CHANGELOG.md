# SimpleOS v1.4 for RG DS — 20261021

Compared to v1.3 `20261014`.

### Home

- Add Activity Log icon in the library.
- add filtering games options
- add edit mode to rearrange icons in the home menu
- add home screen boot animations
- add dark mode themes

### Activity Log

- Two sections: Activity Log (Play time and history) and RetroAchievements (Trophies and progress).
- For each title: Play time, Times played, Average play time, First played, Last played. L / R (or the bottom arrows) change the sorting order.
- RetroAchievements: per-game progress (`unlocked / total` and percentage), trophy list, and a detail screen showing points, Unlocked / Locked status, unlock percentage, and description.
- Long lists can be scrolled with your finger or the D-pad, and the selected row stays visible.
- Dedicated sounds for opening, switching sections, tapping, and exiting.

### In-game

- In DraStic and NNDDSS quick menus, if a RetroAchievements account is linked and the game has trophies, the top screen lists them (icon, name, points).
- The icon at the bottom right of the lower screen swaps the two panels. With trophies on the lower screen, you can scroll through the list and details using your finger; up/down does the same. A or a tap opens the conditions and difficulty, B returns to the list. Tapping the icon again puts the quick menu back on the lower screen.
- Left/right only switch games when the quick menu is on the lower screen.
- Swapping the panels is animated

### RetroAchievements

- Checking the account and trophies no longer pauses the game at startup: it runs in the background.
- Downloading a new list no longer clears trophies already marked as earned.

### PokeDaisy

- PokeDaisy titles can now be launched from the library using their dedicated icon.
- Volume, brightness (including NIGHT and ULTRA LOW), and power mode use SimpleOS toast notifications.
- Anbernic + START closes PokeDaisy and returns to Home.
- Volume remains at the level selected in SimpleOS: the DAC is resynchronized, the volume-up button still responds even if the evdev event is missing, and the level is restored after sleep and resume.
- On the first boot of a flashed image, PokeDaisy is copied to `roms/Ports/pokedaisy`.

### Boot and installation

- On the flashed image, Home remains at `/simpleos`. The first boot no longer creates a second copy on the games card. The Anbernic overlay, which does not have `/simpleos`, continues to use the directory tree on the card.
- SimpleOS startup, autostart, and paths now check `/simpleos` first.
- The first boot of the flashed image installs NNDDSS on the card and creates the save folders (`saves/NNDDSS` and `nnddss/User`).
- A second SimpleOS loop no longer starts during boot.
- The DSperate library is now also read from `roms/nds`, in addition to `ROMS/NDS` and `Roms/NDS`.
